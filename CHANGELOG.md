# Changelog

All notable changes to docuconf-java are documented here. Entries from the first release on are generated by
[release-please](https://github.com/googleapis/release-please) from Conventional Commit messages; see
[CONTRIBUTING.md](CONTRIBUTING.md).

## 0.1.0-SNAPSHOT (unreleased)

Development of the first version (not yet published): typed configuration contracts for Spring Boot
`@ConfigurationProperties`, implementing spec `v1alpha1`. The first release PR turns it into `0.1.0` (or `0.2.0` if
a `feat` lands first).

### Features

* `docuconf-core`: annotations, the contract model, the CUE writer and file input checks (TLS key pairs, CA
  bundles, keystores, structured config files, licence files, binary data).
* `docuconf-processor`: an annotation processor that exports `META-INF/docuconf/contract.cue` at compile time,
  including config-file overlays and `itemMin`/`itemMax` on int lists.
* `docuconf-spring`: Spring Boot auto-configuration that validates variables and files at startup, reports every
  problem at once with stable error codes, and reloads watched overlays.
* Contract-first mode and the shared conformance runner.
* The sample gateway with its golden contract, and the `orders` example.
